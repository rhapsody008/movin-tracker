## search.ts
- `type Filter`, with the Go JSON names as the property names (`kinds`, `rooms`, `statuses`, `category`, `tags`, `vendor`, `text`, `date_from`, `date_to`, `include_archived`, `milestone`, `limit`). All optional. These are the agent tool's arguments later.
- `DEFAULT_LIMIT = 50`, `MAX_LIMIT = 200`.
- `searchEntries(doc: Doc, f: Filter): { entries: Entry[]; total: number }`. The algorithm must be exactly spec §5:
  - Normalise the filter once, with Go's whitespace rules: `lowerAll` collapses inner spaces; `category` and `vendor` are trimmed and lowercased but don't collapse inner spaces.
  - Text words come from `goFields(text.toLowerCase())`.
  - The haystack follows Go's field order and joins with `"\n"`. Copy `search.go` exactly, including where `room` goes.
  - Every word must be a substring of the haystack. Tags use has-all.
  - Vendor matches as a substring. Category is an exact match.
  - The date range is an inclusive **string** comparison, and undated entries match only when no bound is set.
  - `milestone` uses `isMilestone`.
  - Archived entries are excluded unless `include_archived` is set.
  - Limit: `<= 0` or missing means 50, otherwise `min(limit, 200)`. `total` counts all matches.
  - Sort with a **stable** sort by `updated`, descending, as a string comparison (`a < b`, not `localeCompare` and not `Date`). Ties keep document order.
  - Return clones.
- `decodeFilter(args: unknown): Filter` is for tool args. Go unmarshals JSON into `Filter`, so a wrong type is an error. Throw `ValidationError` naming the field, for example `limit must be a whole number`. Go's message here is a raw json error that the agent wraps, so we choose the wording. Unknown keys are ignored, as in Go. Write a short comment saying which wording you chose and why.

## agenda.ts
- `MAX_ASK_DAYS = 7`.
- `addDays(day, n)`: date-only arithmetic on `YYYY-MM-DD` in UTC (`Date.UTC`). It returns `""` for an invalid day, using the same validity rule as `validDate`. Port `sched.AddDays`.
- `agenda(doc, today, since): { today: Entry[]; ask: Entry[]; overdue: Entry[] }` and `isQuiet(a)`, exactly as in spec §6:
  - An invalid `today` gives an empty agenda.
  - `since` that is `""` or invalid becomes yesterday; clamp it to `today - 7`.
  - Skip archived, done and undated entries.
  - Today-bucket entries can be any kind. Everything else must be a task dated before today.
  - Sort with a stable sort by `date + " " + (time ?? "99:99") + " " + created`.
  - Return clones.
