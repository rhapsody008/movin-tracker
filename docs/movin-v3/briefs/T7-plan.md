# T7 plan: delete Go, move `app/` to the root, tag `v2.0.1`

## 1. Goal and assumptions
- Remove Go v1, move `app/` to the root, and ship `v2.0.1` with no behaviour change.
- The Flux pin is `>=2.0.0`, so a `v2.0.1` tag deploys by itself.
- `deploy/` is not touched at all. The liveness probe hardcodes `/srv/app/src/main.ts` (`deploy/k8s/base/deployment.yaml:60`), so the image keeps `/srv/app`.
- I did not read `app/vitest.config.ts`, `app/test/s3-setup.ts`, `.env.example` or `app/.gitignore`; the coder checks them where noted.

## 2. Decisions
1. **Goldens become frozen fixtures.**
   - Delete `app/golden/` in T7.1: the generators import `internal/*` and cannot compile without it.
   - Keep every `testdata/*.go.json` and `*.go.err` as data, never hand-edited. There are no regenerate targets today (only README commands), so nothing replaces them.
   - Add a short `src/testdata/README.md`: the goldens were generated by Go at commit `<T7.1 parent SHA>`; new behaviour gets ordinary TS tests.
   - Keep `fixtures/entries.sample.json` (`eval/chateval.ts` and its test read it).
   - Leave `reference/`, `unitmaterial/` and `tmp/` untouched.
   - Delete the root `static/` in T7.1: it is the Go v1 page and blocks `git mv app/static static`.
   - Delete `app/tools/side-by-side.sh` in T7.1: it needs a running Go app.
2. **Two commits, each green in CI.** T7.1 leaves a thin root Makefile that delegates to `app/`.
3. **Poppler needs a TS replacement.**
   - `Dockerfile.test` and the `runtime` stage are separate `apk add` runs on a `~25.12` pin, so they can drift by a patch release.
   - `ts-test` runs on amd64 only; the Go step ran on amd64 and arm64.
   - Add a `poppler-test` stage on `runtime` that runs the two converter tests, and keep the CI step under the same name.
4. **Paths after the move.**
   - `src/config.ts`: `../../docs` becomes `../docs`, and the image copies the guide to `/srv/app/docs/admin-guide.md`. This is the only layout change.
   - `static-disk.ts` stays `../../static`, which is still `/srv/app/static`.
   - `eval/chateval.ts`: `../../fixtures` becomes `../fixtures`.
5. **v1 hotfix.** Keep the five-line `v1.*` guard, moved to the new first job, with a shorter comment. Add one README line: v1 is tag `v1.0.1`; cut `release/1.0` from it only if needed. Flux ignores 1.x now anyway.
