# T2.1 — HTTP server core: REST + SSE for entries, health, auth, static fallback

## Goal
Port the Go HTTP layer's core to TypeScript on `node:http`, so the browser page and the tests see the same bytes as Go. T2.1 covers:
- the router, auth, request logging, body decoding, the error mapping (`fail`) and the static catch-all;
- the entries REST routes, `PUT /api/meta`, undo, the SSE stream `/api/events`, and `/healthz` and `/readyz`.

Admin, settings and docs routes are T2.2. Serving the real `static/` page and `main.ts` are T2.3.

## Design (decided)
- **`app/src/entries/changetext.ts`:** a faithful port of `fmtDate`, `Money`, `Summary` and `ChangeText`, including Money's floor/round/`cents==100` carry and the `diff` list order. T3 and T4 will import it from here.
- **`app/src/server/` layout:** suggested, adjust as needed, but keep one concern per file.
  - `http.ts`: `writeJSON` (Content-Type `application/json`, `goMarshal(v) + "\n"`), `writeErr`, `httpError` (Go `http.Error`: `text/plain; charset=utf-8`, `nosniff`, body plus `\n`), `decodeBody` (1 MiB cap → 400 `Request body must be JSON: http: request body too large`; empty → `…: EOF`; first JSON value only), and `fail`.
  - `router.ts`: a tiny method-plus-pattern router with `{id}` single-segment wildcards, percent-decoded once.
    - It has **no 405**: an unmatched method falls through to the catch-all, exactly as §9.5 says.
    - HEAD is served by the GET handler.
    - Go's path-clean 301 comes from §9.6; implement it if cheap, otherwise list it as a difference.
  - `auth.ts`: §2.1. `logging.ts`: §2.3.
  - `entries.ts`: the routes in §1.2 rows 1–6.
  - `events.ts`: SSE, §3.
  - `health.ts`: §4. `static.ts`: the catch-all from §2.5.
    - It serves from an injected `StaticFiles` interface (`get(name) → {body, type} | null`), not from disk. T2.3 adds the disk/embedded source.
    - It answers JSON 404 `no such endpoint` for `/api/*`, Go's `404 page not found\n` otherwise, and the `/index.html` → 301 `./`.
  - `server.ts`: `createServer(deps)`, which returns `{ handler(req,res), closeStreams() }`. The deps:
    - `entries`, `docs?` (a `Syncer` or null), `store` (for readyz), `log`, `staticFiles`;
    - `authHeader`, `allowedEmails`, `devEmail`, `sseHeartbeatMs` (default 25 000);
    - `settings?` (only so `fail` and T2.2 can plug in).
- **JSON field order:** every response body and SSE payload goes through `goMarshal`.
  - Structs use `Ordered` in Go struct order.
  - Go map bodies (the 409 conflict body, `{"joined","started"}`) are written with keys sorted.
  - The snapshot body reuses `snapshotJson`, plus `\n` for REST and nothing extra for SSE.
- **Decode errors:** keep the 400 status and the `Request body must be JSON: ` prefix.
  - The tail is a short, stable text of your own. `EOF` for an empty body, and `http: request body too large` for oversize, must match Go exactly.
  - List this as a known difference.
  - Duplicate keys: last one wins, as in Go.
  - Trailing data after the first value: ignored, as in Go. Make the scanner find the end of the first value; `gojson.ts` may already have what you need.
- **`fail` order** follows §1.5 exactly:
  - The entries-conflict and undo-stale bodies re-read `current()` and ignore its error. If that fails, the body is `{"doc":null,"error":…,"etag":""}`.
  - Use `ValidationError` from `src/errors.ts`, and map settings' `ConflictError` with its own text and no `doc`.
- **SSE:**
  - Headers are exactly as in §3.1, then `flushHeaders()` synchronously.
  - The first `entries` event comes before any ping. `docs` events re-read the docs view.
  - `: ping\n\n` is sent every `sseHeartbeatMs`.
  - On `close`, clear the timer and both subscriptions.
  - `closeStreams()` ends every open stream.
  - Docs events need a `docsView`. Write the minimal `docsView(syncer)` builder now, in `src/server/docsview.ts` (§1.4, the `docsView` row), because T2.2's `GET /api/docs` reuses it. If the syncer is null, there are no docs events.
- **Not in T2.1:**
  - `POST /api/chat`, which is T3.5. Until then it falls to the catch-all's JSON 404; note that in a comment.
  - The admin and settings routes. Their paths also fall to the catch-all until T2.2.

### Go golden transcript (the byte contract)
Add `tmp/t21-golden/main.go` (`//go:build ignore`). It:
- wires the real Go `server.Server` with a memory store, a fixed clock (`entries.Service.SetClock`), `TZ` `Asia/Singapore`, `DevEmail` empty and `AllowedEmails` `{zy@…, partner@…}`, and a `fstest.MapFS` with `index.html` and `icon.svg`;
- runs a fixed script of about 40 requests through `httptest.NewServer`;
- writes `app/src/server/testdata/transcript.go.json`: an array of `{name, method, path, reqHeaders, reqBody, status, headers: {content-type, etag, location, cache-control, x-content-type-options}, body}`.

The script must cover:
- every T2.1 route's success and error paths, including:
  - `GET /api/entries` with `If-None-Match` → 304;
  - the 400 texts;
  - 404 entry and 404 change;
  - delete twice;
  - undo, then undo again → 409 with `doc`;
  - `PUT /api/meta` with each of its 400 texts;
- an entry whose title contains `<`, `&` and `"`, whose estimate is `1234.5`, with a room, date, time and vendor, plus a patch of every diff field so `ChangeText`'s `Updated: … (…)` list is exercised;
- auth 401 and 403, case-insensitive email;
- `/healthz`, `/readyz`, `/icon.svg` without auth;
- `GET /`, `GET /index.html` (301), `GET /nope.txt`;
- `GET /api/nope` and `PUT /api/entries` (the method-mismatch JSON 404), and `POST /healthz`;
- a 1 MiB + 1 body, an empty body, and a body with trailing data.

The TS test replays the same script against the TS server, with the same clock and the same memory-store starting state, then compares status, the listed headers and the body bytes. Before comparing, both sides are normalised:
- ULIDs (26 Crockford chars) → `<ID1>`, `<ID2>`…, numbered by first appearance;
- ETag values → `<ETAG1>`…, numbered by first appearance;
- the decode-error tails, which are documented as differing, are masked after the prefix.

Everything else must be byte-equal. If something can't be, stop and report it rather than masking more.
