## Build
- **`index.ts`**
  - The `Index`, `Doc` and `Sync` types, plus `PageText`.
  - Go field order and omitempty exactly as in spec §1.
  - `encodeIndex`: indented like `MarshalIndent(…, "", "  ")`, with Go HTML escaping. Text blobs are compact.
  - `decodeIndex` drops unknown fields.
  - Also port `AssignID`, `SkipReason`, `textKey`, the newer-version guard, `ConvertVersion` and every other exported helper.
- **`sync.ts`**: `createSyncer({ store, converter, summariser?, notify?, log, now? })`.
  - Single flight: a concurrent caller gets the running run's result.
  - ETag-guarded writes with 4 attempts and a per-run memo.
  - The `apply`/`update` rules, the counters and the exact log messages and fields.
  - The `ErrConflict`/`ErrNewerIndex` texts.
  - `index()`, `refresh()`, `pageText()`, `running()` and `subscribe()`.
  - One `stamp` per run, shared by every field written in that run (trap 5).
  - The index generation counter for the library rebuild (trap 7).
- **`summary.ts`**
  - The `Summariser` interface, `tidySummary`, `firstText` (3000 code points), the prompt text as a constant, and `retrySummary` behaviour.
  - The LLM-backed summariser is **not** built here. It needs the LLM layer (T3.1). Add a `// T3.1:` note where it plugs in, and add a line to `docs/movin-v3/progress.md` under T3.1: "wire LLM summariser for docs (summary.ts)". That one-line edit of `progress.md` is allowed.
